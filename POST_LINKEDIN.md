🤖 **KOF Agent — Gere código KOF a partir de texto em português**

Um agente neural que entende "Criar uma API REST" e gera o código KOF correto.

**O que faz:**
→ Brain: analisa intenção (create, repair, search...)
→ Neural: identifica padrão (http, class, record...)
→ Generator: gera código KOF pronto

**Arquitetura:**
→ 100% no navegador (Edge AI)
→ Zero servidor, zero custo
→ Pré-treinado (carrega instantâneo)
→ TensorFlow.js opcional para treino adicional

**Stack:**
→ JavaScript + TensorFlow.js
→ Web Workers (paralelo)
→ KOF Brain (traduzido de 68_brain.kf)

**Números:**
→ 20 padrões KOF
→ <3ms latência
→ 2KB modelo pré-treinado
